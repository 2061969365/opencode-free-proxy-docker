==================================================
 OpenCode Free Proxy 使用说明
==================================================

【一、启停】
- 开启：双击 start.bat（自动走 v2ray 代理 127.0.0.1:10809）
- 关闭：双击 stop.bat
- Web 面板：http://127.0.0.1:4096 （可看模型列表、日志、映射）

==================================================
【二、Claude Code / CC Switch 配置】
==================================================
Base URL : http://127.0.0.1:4096
API Key  : not-needed （任意字符串，代理不校验）
模型     : claude-sonnet-4-6（自动映射到 deepseek-v4-flash-free）

注意：
- Claude Code 的 Base URL 不带 /v1（它自己会追加 /v1/messages）
- 其他 Claude 模型名映射见 config/mappings.json

==================================================
【三、opencode / OpenAI 兼容客户端配置】
==================================================
Base URL : http://127.0.0.1:4096/v1
API Key  : not-needed
模型     : deepseek-v4-flash-free

可用免费模型（任意 -free 结尾）：
  deepseek-v4-flash-free  （推荐，有推理能力）
  big-pickle
  mimo-v2.5-free
  nemotron-3-ultra-free
  north-mini-code-free
  ling-3.0-flash-free
  laguna-s-2.1-free

（列表里其他不带 -free 的是付费模型，不要用）

==================================================
【四、配置文件】
==================================================
config/settings.json  端口设置，默认 4096，改完需重启
config/mappings.json  模型映射表：
                      左边 = 客户端请求的模型名
                      右边 = 实际免费模型
                      改完无需重启，Web 面板也能改

==================================================
【五、注意事项】
==================================================
1. 免费模型有限流（约每分钟几次请求），适合轻量任务
2. 依赖 v2ray 代理连接 opencode.ai，代理没开则连不上
3. 上游地址/鉴权头写死在代码里（src/constants.js），无配置入口
